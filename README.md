## 🤖 Machine Learning Projects

### Content Refresh Prioritization | FlyRank AI

Worked on a machine learning project focused on identifying and prioritizing content pages for potential refresh using search performance, engagement, and content freshness signals.
[📂 Explore Repository](https://github.com/surajprai2111-ui/ML-assignment)

- Analyzed **30,000 records with 44 features** to explore content performance and predictive signals.
- Developed and evaluated a **Random Forest model** against a baseline using Average Precision.
- Achieved **0.5894 Average Precision**, compared with a baseline score of **0.5008**.
- Implemented **client-grouped validation**, training on 25 clients and testing on 7 unseen clients to assess generalization and reduce data leakage.
- Analyzed feature importance and model performance to support data-driven content prioritization.
